# 自适应容错的先行工作

这一册决定"自适应"这个卖点还剩多少。

| 工作 | 出处 | 机制 | 数字 |
|---|---|---|---|
| **Jacobs et al., Reconfigurable Fault Tolerance (RFT)** | **ACM TRETS 5(4), 2012** | 在轨 FPGA 按辐射强度在 ABFT / DWC / TMR 之间切换，带 performability 模型 | 相对**静态 ABFT** 把不可用率改善 **85%**；相对**静态 TMR** 把 performability 改善 **128%**。DWC 17.5% / TMR 76% 片上资源 |
| PROFiT + CRAFT | ACM TACO 2(4), 2005 | 多版本代码 + 按区域选保护等级 | "多版本 + 可配置可靠性"的历史源头 |
| Relax | ISCA 2010 | 程序员声明的分级恢复：重执行 / discard / 向上传播 | 恢复块分类的先例 |
| BRAINIAC | ISCA 2015 | 廉价近似 → 更好近似 → 精确，三档递进 | 与"分级恢复"一对一 |
| E.6 一族（可重构辐射自适应） | 见 `docs/survey/part_E_riscv_space.md` | 动态重配置 | — |
| Safe-NEureka | arXiv 2602.04803, 2026 | DNN 加速器两模式：冗余模式（DMR+时间分散）/ 性能模式 | 功耗开销 <8%，代价是峰值算力减半 |
| RadML / Space-Radiation-Tolerant | GitHub, 2025 | 自适应保护 + Reed-Solomon | 工程框架，无同行评议 |

## 对我们的意义（要在论文里正面处理）

1. **"按辐射强度切换保护等级"在 2012 年就有同行评议工作，而且是在轨 FPGA 场景、
   带 performability 模型、明确给出相对静态 ABFT / 静态 TMR 的改善幅度。**
   我们的自适应层不能声称这个概念是新的。
2. RFT 的分层结构（ABFT 覆盖得到的用 ABFT，覆盖不到的用 TMR/DWC）**与我们的
   三层框架同构**。差异只能落在：判层是**自动**的（搜索 + 可约性判据）而不是人工指定，
   以及我们是**编译器 + 通用 C 程序**而不是 FPGA 比特流。
3. 没有被占的位置是**切换规则本身的统计保证**：RFT 用的是环境模型驱动的策略，
   我们用 SPRT 给出指定的 α/β，并且算出了"检测延迟 × 低保护暴露"对收益的封顶。
   这条（见 `docs/HANDOFF.md` 第 8、11、12 节）是目前真正属于我们的。
4. 但要诚实报告第 12 节的否证：**合格的 LOW 档在这个代码基上不存在**，
   所以自适应的收益目前是负的。RFT 能成立是因为它的 LOW 档是 ABFT，
   而它的负载（HSI / SAR → 矩阵乘、矩阵求逆、FFT）**全部**可被 ABFT 覆盖；
   我们的套件只有 48.7% 的工作量可被覆盖。**覆盖面是自适应能否成立的前提条件**，
   这个因果链是我们的数据给出的。
