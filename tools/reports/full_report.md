## 故障注入

LLVM Pass 在 IR 层插桩，运行时在选定的动态执行点把指定比特取反。

### 注入对象
| 类别 | 插桩对象（IR 层）|
| --- | --- |
| 浮点 | double/float 算术与一元运算的结果 |
| 整数 | 16/32/64 位整数算术与逻辑运算的结果 |
| 类型转换 | 位宽/类型转换的结果 |
| 访存 | load 指令的结果值 |
| 地址 | 地址计算中的可变下标|
| 比较/分支 | 驱动分支/选择/跳转表的比较结果 |

### 注入模式
| 模式 | 怎么选故障 |
| --- | --- |
| 单比特均匀 | 命中点里均匀抽一个执行序号，64 位里均匀抽一位翻转 |
| 位域定向 | 限定在 符号位(63) / 阶码(52-62) / 高位尾数(32-51) / 低位尾数(0-31) |
| 空间多比特 | 从起始位连续取反 1/2/4 位（SEU / DBU / QBU）|
| 时间连发 | 一次运行注入 k 个独立故障，k = 1…8 |

## 自适应调度（SAMPEX / Alsat-1 / GEO 耀斑）

- 按辐射率 λ 动态选方法：静默段无防护、辐射段升强防护。
- 时间预算 ε = 每个时间步允许的残余失效率上限(1e-4 faults/s)；某步残余 λ·e 超 ε 即"违约"，全程不违约即"容错达标"。
