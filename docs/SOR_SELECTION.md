# SoR 边界选择问题(P3)

把"选哪个圈"从人设旗标变成一个可解的决策问题。这是框架脊椎:
手调的并列旗标叫堆砌,一个选择过程吐出的配置叫框架。

## 决策变量:圈 = 穿越口子集

圈 S ⊆ {V, L, A, C},每位是一个"该穿越口是否纳入圈"的二元决策:

- **V** = value 计算(圈内复制,向量化)
- **L** = load input-replication(抗共模双读)
- **A** = address/cast(值变地址之前校验)
- **C** = control(cmp_branch 出圈校验)

store 的 output-comparison 是圈非空时的强制动作,不是自由决策,不计位。

## 代价与覆盖(实测,不拍脑袋)

每个穿越口 i 纳入圈:
- 带来开销增量(来自 `results/framework_eval.csv` 与 `results/crossing_coverage.csv`)
- 对其目标类别的 native SDC 施加覆盖降幅 `cov[i,cat]`(实测)

记 native 各类 SDC 为 `s[cat]`(`results/effect_profile.csv`)。

## 两个模型:分离 vs 联合

**分离模型(文献默认,把保护当可加)**:各穿越口独立,残余 SDC
```
r[cat](S) = s[cat] * Π_{i 覆盖 cat, i∈S} (1 - cov[i,cat])
```

**联合模型(本框架,含 P2 实测耦合)**:向量化把 value 做便宜的同时,把 cast 子切片
的 native 率抬高 κ(实测 κ≈8.5pp,3.6→12.1,见 `results/nonseparability.csv`):
```
s'[cast] = s[cast] + κ * [V∈S]
r[cast](S) = s'[cast] * (1 - cov[A,cast] * [A∈S])
```
分离模型把 `s[cast]` 当常数,于是**只要 V∈S 而 A∉S,它就系统性低估 cast 残余**。

## 环境驱动的选择

给定轨道 SEU 率 λ(CREME96),可靠性目标 τ(λ) 随 λ 升高而收紧。选择:
```
S*(λ) = argmin  Cost(S)   s.t.   Σ_cat r[cat](S) ≤ τ(λ)
```
λ 升高 → τ 收紧 → 逼迫更大的圈。这就是"圈随环境呼吸",且只有一个控制量(圈)。

## 要证明的点

分离优化器忽略 κ,在某段 λ 会选一个**含 V 不含 A** 的圈(它以为 cast 只有 3.6%、已达标);
联合模型揭示该圈的真实 cast 残余 ~12%,超过 τ → 分离的选择其实不可行。
联合优化器会在纳入 V 的同时纳入 A。**即:忽略 P2 耦合会把圈定错尺寸。**

## Demo 结果(全部参数实测,`experiments/measure_sphere_selection.py`)

实测输入(读自 effect_profile / crossing_coverage / nonseparability / framework_eval):

- native 各类 SDC:fp64 8.94 / int 9.79 / cast 3.62 / cmp_branch 29.25 / addr 0.46 / load 11.67
- 覆盖:cov[V,fp64]=0.979,cov[A,cast]=cov[A,int]=cov[C,cmp]=1.000(scalar 实测)
- 耦合 κ(cast)=8.5pp
- 开销:V(向量化 value)1.68× / A(int-TMR)6.97× / C(cmp-TMR)4.07×

扫 τ(= 容忍总残余,τ 越小 λ 越高),对比分离/联合优化器各自选的圈:

| τ | λ∝B/τ | 分离选圈 | 真实残余 | 联合选圈 | 真实残余 | 判定 |
|---|---|---|---|---|---|---|
| 60.5 | 0.99 | {V} 1.68× | **63.4** | {C} 4.07× | 34.5 | 分离静默不可行 |
| 57.3 | 1.05 | {V} 1.68× | **63.4** | {C} 4.07× | 34.5 | 分离静默不可行 |
| 31.6 | 1.90 | {V,C} 6.83× | **34.2** | {A,C} 28.4× | 21.1 | 分离静默不可行 |
| 28.4 | 2.11 | {V,C} 6.83× | **34.2** | {A,C} 28.4× | 21.1 | 分离静默不可行 |

17 个采样点中 4 点出现分离优化器**静默不可行**:它按"cast 只有 3.6%"判 {V} / {V,C} 达标,
但按实测 κ 评估,这些圈真实残余(63.4 / 34.2)已超 τ。

## 两个落到纸面的结论

1. **向量化 value 在总残余层面几乎白干**:联合模型下 {V} 把总残余从 63.7 只降到 63.4
   —— V 对 fp64 的 -8.75pp 几乎被它对 cast 的 +8.5pp 抵消。便宜不等于有用。
2. **A 的入圈价值依赖 V**:V 不在圈时 cast 仅 3.6pp,A(6.97×)不值;V 在圈时 cast 升到
   12.1pp,A 才值得付。**A 与 V 不能独立决策** —— 这就是选择层的非可分离,正是分离优化器
   踩空的原因。

## 口径与后续(诚实边界)

- demo 把 A 的 cast 覆盖建模为可迁移到向量化后的 cast。**此假设已被实测证实**
  (`results/transfer.csv`):int-TMR 接入向量化路径后,cast SDC 9.4→0.0、int 4.9→0.0。
  机制上 int-TMR 覆盖的是可注入的**标量** cast(注入器不碰向量 cast),而那正是浓缩后
  残留的关键 cast。故联合优化器选 {V,A} 由模型预测升级为实测事实。
- 开销按穿越口乘性组合是一阶近似(开销本身可能也非可加);本 demo 的决策分歧由覆盖/残余侧
  驱动,开销精度不影响定性结论。
