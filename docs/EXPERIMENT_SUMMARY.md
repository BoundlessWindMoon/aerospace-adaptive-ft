# 实验现状

## 结论

1. 近似三模冗余在浮点与访存数据通路上有效，SDC 从 16.08% 降到 2.83%，从 18.18% 降到 7.87%。
2. 本方法与精确三模的可靠性无显著差异，指令开销低 14%。
3. 整数算术、类型转换、地址计算、控制流四类几乎没有被覆盖。控制流是失效率最高的一类，达 48.33%。
4. 阈值投票对高位翻转有效、对低位翻转无必要：符号位与阶码翻转的恢复率 75%，低位尾数降到 25%，而低位尾数本身不产生 SDC。
5. 单一全局阈值适配不了所有负载，阈值从 1e-7 放宽到 0.5 时无故障误报从 23.67% 降到 0，恢复率同时从 24.35% 降到 3.59%。

## 指标

| 指标 | 含义 |
|---|---|
| SDC% | 输出静默错误的试验占比，浮点负载相对误差超过 1%，整数负载任何非零偏差 |
| DUE% | 检出但无法恢复，或进程崩溃挂死的试验占比 |
| 检出并恢复% | 表决器检出且恢复后输出可接受的试验占比 |
| 指令倍率 | 受保护版本的动态指令数相对无保护版本 |
| 无故障误报% | 不注入故障时表决器误触发的比例 |
| MTTF | 平均无故障时间 |
| MWTF | 单位有用工作对应的失效数之倒数 |
| 每任务失效数 | 90 天任务期内的期望失效次数 |

SDC、DUE、检出并恢复三项附 95% 置信区间。

## 故障怎么注入

> 编译期由一个独立的 LLVM Pass 在被测程序里插桩，运行时在选定的那一步把指定比特
取反。

**注入位置由故障类别决定。** 

| 类别 | 插桩对象 | RV64GCV 落点 |
|---|---|---|
| fp64 | double 算术与一元运算的结果 | fadd.d, fmul.d |
| fp32 | float 与双路向量 float 算术的结果 | fadd.s, vfadd.vv |
| int_arith | 16/32/64 位整数算术与逻辑运算的结果 | add, mul, sll, and |
| cast | 位宽与类型转换的结果 | fcvt, sext.w |
| load | load 指令的结果值 | lw, ld, flw, fld 的目的寄存器 |
| addr | 地址计算中的可变下标，扰动限制在正负 3 个元素 | sw, lw 的地址寄存器 |
| cmp_branch | 驱动分支、选择、跳转表的比较结果 | slt, feq.d 加 beq, bne |

**四种注入模式。** 执行序号在该类别插桩点的总命中次数里均匀抽。

| 模式 | 怎么选故障 |
|---|---|
| 单故障均匀采样 | 抽一个序号，64 位里均匀抽一位 |
| 位域定向 | 抽一个序号，位限定在符号位 63、阶码 52-62、高位尾数 32-51、低位尾数 0-31 |
| 空间多比特 | 抽一个序号，从 0-59 抽起始位，连续取反 1、2 或 4 位 |
| 时间连发 | 独立抽 k 个序号，各抽一位，k 取 1 至 8 |

## 消融

### 逐类别 SDC%
- fp64 与 load 有收益
- int_arith 与 cast 无收益，
- addr 无收益
- cmp_branch 无收益，失效率却最高

> 本表口径是逐负载等权（`rq8_inst_category_breakdown.csv`，fp64 只覆盖 10 个负载）。
> `docs/METHOD.md` 的同名表用套件等权（`rq1_aggregate.json` 的 `by_category`），
> 同一量数值不同，例如 fp64 无保护 16.08 对 28.98。引用时必须标口径。

| 方法 | fp64 | int_arith | cast | load | addr | cmp_branch |
|---|---|---|---|---|---|---|
| 无保护 | 16.08 | 24.22 | 11.32 | 18.18 | 1.77 | **48.33** |
| SWIFT | 2.83 | 24.22 | 11.37 | 17.97 | 1.77 | **48.33** |
| LLTFI-SID | 8.42 | 24.31 | 11.37 | 18.18 | 1.77 | **48.33** |
| 精确三模 | 1.75 | 23.68 | 9.41 | 7.81 | 1.77 | **48.33** |
| 本方法 | 2.83 | 22.99 | 9.46 | 7.87 | 1.77 | **48.28** |



### 翻转位置，决定阈值投票值不值得

- 失效几乎全部来自符号位与阶码。这两处的恢复率 75%
- 低位尾数降到 25% 但它本身不产生 SDC。

| 翻转位域 | 无保护 SDC% | 本方法 SDC% | 本方法检出恢复% |
|---|---|---|---|
| 符号位 | 67.75 | 0.0 | 75.0 |
| 阶码 | 58.75 | 0.0 | 75.0 |
| 高位尾数 | 3.25 | 0.0 | 54.75 |
| 低位尾数 | 0.0 | 0.0 | 25.0 |

### 表决阈值，证明需要校准

- 阈值收紧提高恢复率但制造误报，放宽消除误报但恢复率掉到三分之一。

| 1e-5 | 5.88 | 18.92 | 1.73 |
| 5e-5，默认 | 5.88 | 17.73 | 1.84 |
| 1e-3 | 0.00 | 11.31 | 2.02 |
| 0.05 | 0.00 | 6.90 | 2.96 |
| 0.5 | 0.00 | 3.59 | 4.12 |
