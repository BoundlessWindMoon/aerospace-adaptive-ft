# 结合已有工作：先拿收益，再加学术感

两个结论：
1. **P1 可以免费加强成"双资源律"**，用的是你已经跑完的 cmp-DMR 数据，不用新实验。
2. **P2 换掉**。更值得做的第二问题是：**检测门限该由谁决定**——这个问题你已经把数据跑到门口了
   （ABFT 的 κ 扫描 + 68% 检出地板 + GNC/orbit 那几个核），而且它和 P1 是真耦合，不是并列。

## 一、P1 的免费加强：律不只管车道，也管发射槽

现在 P1 的律写在 SIMD 车道上。但你已经有一个同构的实测点在另一种资源上：
**cmp-DMR（复制比较骑 ILP 空槽）实测 cmp_branch 29.2% → 0.0%，边际开销 ≈ 0**。

这不是另一个机制，这是同一条律在"发射槽"这个资源上的实例。把 P1 的陈述从

> 车道闲着时冗余免费

改成

> **冗余的代价等于它所占资源的紧缺程度；程序在某一维留下的余量，决定该维上的冗余是否免费。**
> 车道（SIMD 宽度）、发射槽（ILP）、带宽（校验流量）是三个可量化的维度。

好处有三个，全部零成本：
- 覆盖面从"FP 数据并行循环"扩到"分支/整数/访存"，不再是单点律。
- `cmp_branch` 的 marginal≈0 和 `int_arith` 残差码的 1.6% 残余/2.06× 都变成律的**验证点**，
  不是互不相干的机制清单。
- 回答了一个审稿人一定会问的问题："你的律只在可向量化的核上成立吧？"——不是，
  它换资源维度就继续成立。

要补的只有一件事：给每个维度一个**余量的度量**（车道：$1-I/I_{ridge}$；
发射槽：IPC 相对峰值的缺口；带宽：$1-$ 带宽利用率），然后验证"余量 → 冗余边际成本"的单调关系。
PMU 口径你已经全有（`gap_nonintrusive` 那套）。

**另一个零成本的收获**：wide-DMR 现在在归约（gemm/2mm/3mm）上 bail。按律，归约是算力受限侧，
本来就该走校验而不是复制 —— 所以这个 bail 不是缺陷，是律的预测。
省掉"把 wide-DMR 扩到归约"这件原本要花两周的工程，这本身就是律的第一个工程收益。

## 二、第二问题（替代 P2）：检测门限该由谁决定

### 问题

浮点校验必须设一个门限，把舍入误差和真故障分开。门限设低了误报，设高了漏检——
**漏掉的那一部分不是"检不到的故障"，而是"幅值小于门限的故障"**。
你的 ABFT 68% 检出地板就是这个：κ 从默认收到 0.05，检出 68% → 99.5% → 100%，代价 1.13–1.15×，
但 κ=0.05 时出现 2 次误报。

现在的做法是**让门限去界定舍入误差**：A-ABFT（DSN'14）自主算出内积的舍入误差界取 3σ；
V-ABFT（2026）把界收紧，并给了两个很有用的数字——A-ABFT 的门限比真实舍入误差大
**160–4200×**，V-ABFT 收到 **7–20×**（FP32/64）；逐位检出率上，指数位 11–14 是 100%，
第 10 位 99.99%，而第 7–9 位只有 0.01–73%。也就是说这条线已经把门限做到了接近舍入误差下界，
**但那个"漏检带"仍然存在，而且没人问它会把下游怎么样。**

> **门限应该由舍入误差决定，还是由下游消费者能容忍什么决定？
> 同一个核，喂给收缩型消费者（Kalman/PID 闭环）和喂给累积型消费者（轨道外推）时，
> 最优门限会差多少？**

### 为什么是新问题

- A-ABFT / V-ABFT 把门限当成**校验器自身的性质**（界住舍入误差、零误报），
  逐位检出率是作为"能力"报出来的，没有接到应用后果上。
- ApproxABFT 确实把门限接到了应用（DNN 精度），但用的是**贝叶斯搜索**逐层调参——
  是拟合，不是定律，换网络换层就得重搜。
- HPC 那条 partial verification 的理论（Benoit/Cavelan/Robert）把探测器的 recall 当**给定参数**，
  不问 recall 是怎么来的、漏掉的那部分有什么后果。
- 控制侧的容错（FTC）处理的是作动器/传感器故障，不是计算中的静默数据损坏。

所以"漏检带的幅值 → 下游动力学 → 任务级后果"这条链，现在是断的。
而**空天恰好是这条链有意义的场景**：星上计算几乎全部喂给一个闭环（姿控、滤波）或一个积分器
（轨道外推），消费者的误差动力学是已知的、可解析的。

### 方法

设校验器的检测地板是 $\delta$（由门限决定），下游消费者每步对扰动的增益是 $\rho$，
任务容差是 $\tau$，时域长度 $K$：

- **收缩型消费者**（稳定滤波/闭环控制，$\rho<1$）：扰动按 $\rho^k$ 衰减，稳态误差 $\approx\delta/(1-\rho)$
  $$\Rightarrow\ \delta_{max}=\tau(1-\rho)$$
- **累积型消费者**（开环积分、$\rho\ge1$）：误差随步数累积
  $$\Rightarrow\ \delta_{max}\approx\tau/K\ \ (\rho=1),\qquad \delta_{max}\approx\tau\,\frac{\rho-1}{\rho^{K}-1}\ \ (\rho>1)$$

$\rho$ 不需要调参：闭环的 $\rho$ 来自系统矩阵与增益（Kalman 的 $(I-KH)A$ 谱半径、PID 的闭环极点），
轨道外推的 $\rho$ 来自积分器的误差传播。这些量在代码里是常量或可静态拿到的参数。

于是门限的选法从"界住舍入误差"变成**两边夹**：
$$\delta_{round}\ \le\ \delta\ \le\ \delta_{max}=f(\rho,\tau,K)$$

- 若 $\delta_{max}>\delta_{round}$：区间非空 → **便宜的校验就够了**，而且可以把门限放松到 $\delta_{max}$，
  误报趋零、代价回到 1.04× 那一档。
- 若 $\delta_{max}<\delta_{round}$：区间空 → 校验在原理上不够，**必须换复制**。

**这就是和 P1 的真耦合**：P1 的律告诉你算力受限侧该走校验，而这一条告诉你**校验在哪里够用、
哪里不够**。两条合起来才是一个完整的选择规则，而不是两个并列的小结论。

### 可否证的预测

1. 收缩型消费者下，注入幅值 $<\delta$ 的故障，末态误差应服从 $\delta/(1-\rho)$，
   拟合斜率落在 $1/(1-\rho)\pm20\%$。
2. 同一个 gemm，放进 Kalman 和放进 orbit_rk4，算出的 $\delta_{max}$ 应差若干个数量级
   （$\tau(1-\rho)$ vs $\tau/K$）。这是本条最醒目的主张。
3. 在 $\delta_{max}>\delta_{round}$ 的核上，把门限从 κ=0.05 放回 κ=1，
   **任务级失效率不变、代价从 1.13–1.15× 回到 1.04×、误报归零**。
   —— 这是直接的收益，也是"68% 检出不是缺陷"的论证。

### 实验

1. **幅值分层注入**：按幅值分桶注入（现在的注错是按位翻转，要加一个"按相对幅值"的模式），
   量末态误差 vs 幅值，对三类消费者各出一条曲线。
2. **$\rho$ 的静态提取与验证**：从 Kalman/PID 的系数算 $\rho$，与实测衰减率对照。
3. **门限扫描 × 消费者**：κ 扫描重做一遍，但判据从"检出率"换成"任务级失效率"，
   显示最优 κ 随消费者移动。
4. **代价收益**：上条最优 κ 下的开销与误报，对比 V-ABFT 式（只界舍入误差）的门限。
5. **跨核普适**：Cholesky/LU 的 Freivalds 校验器上重复 1–3，确认律与校验器种类无关。

### 已有资产

`gnc_kalman`（闭环收缩）、`aocs_pid`（闭环）、`orbit_rk4`（开环累积）、
`cnn_cls_decision`（决策翻转=天然的 $\tau$）这四个核是**正好**需要的三类消费者，
它们现在在论文里只是"空天相关负载"，在这条线下变成核心实验对象。
加上 ABFT 的 κ 扫描（68/99.5/100% + 误报计数 + 1.13–1.15×）、
Freivalds 的 Cholesky 1.08×/LU 1.03×、`ATFT_SDC_REL_ERR` 这套 QoR 判据，材料基本齐。

要新写的只有两件：按幅值分桶的注入模式（harness 改一处）、从消费者系数算 $\rho$ 的小分析器。

## 三、先做什么（按收益排序）

**立刻有收益，且都服务于上面两条线：**

1. **κ 的理论化**（半天～1 天）：把 κ 从拍脑袋常数换成 $[\delta_{round},\delta_{max}]$ 区间里的取值。
   收益：ABFT 一档的开销从 1.13–1.15× 回到 1.04×、误报归零；而且消掉了你自己定的
   "不许有拍脑袋常数"这条红线上的最后一个违例。
2. **Freivalds 进 pass / 进 FI 主路径**（2–3 天）：P1 的算力受限侧现在只有二维下标矩乘识别器
   （48.7% 动态覆盖），而 Cholesky 1.08× / LU 1.03× 的原型已经验过。
   收益：校验侧覆盖面大幅上移，P1 的"跨越点切换"才有东西可切。
3. **三维余量的度量 + 单调性验证**（1 天）：把 cmp-DMR / int-residue / wide-DMR 的已有数据
   按"余量"重排一次。收益：P1 从单资源律升级成双/三资源律，零新实验。
4. **tmr-generic 的 NaN 语义**（半小时）：`minnum/maxnum` 的中值会丢弃 NaN 操作数，
   NaN 类故障会被记成 masked。这条不改，上面所有覆盖率数字都会被质疑。

**不要再花时间的：** 把 wide-DMR 扩到归约（律说该走校验）；
继续压无结构 FP 的指令级开销（屏障/打包/签名已榨干，真正的杠杆是把核路由到校验侧）。

## 四、合成一篇的骨架

> **保护的代价由它占用哪一种余量决定，保护的充分性由下游能容忍多大的漏检带决定。**

- 第一部分（P1）：余量 → 机制与资源划分。律 $r_{free}=W(1-I/I_{ridge})$，三资源版本，
  编译器按律联合选 (机制, VF, r)。主实验：预测 vs 实测、oracle gap、$W$ 扫描、跨 ISA。
- 第二部分（本文）：漏检带 → 门限。双边夹 $\delta_{round}\le\delta\le f(\rho,\tau,K)$，
  从消费者系数静态算 $\rho$。主实验：幅值分层注入的衰减律、最优门限随消费者移动、代价回落。
- 第三部分（空天层）：把前两部分的选择规则放到 λ(t) 上，用 cross-section/FIT/MWTF 结账
  （见 `docs/LEVEL_A_PLAN.md`）。自适应在这里只是"按 λ 在已有前沿上选点"，不单独立主张——
  这样它就不用再承担论文的一半。
