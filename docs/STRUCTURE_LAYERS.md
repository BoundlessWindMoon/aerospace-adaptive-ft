# 结构化容错:五层结构视角(机制层主叙事)

一句话:**廉价容错 = 跨层榨"结构";计算在哪一层暴露结构,就用那层的便宜机制保护它。**
保护成本由"可利用结构的强弱"决定,而不是逐 kernel 打补丁。

## 结构存在于五个层面

| 层 | 结构是什么 | 免费午餐(便宜机制) |
|---|---|---|
| ① 函数(数学) | 计算的代数性质:可分离/线性/仿射递推/值域 | 不变量检查(校验和/递推核对/成员判断) |
| ② 资源(硬件) | 机器空闲容量:SIMD 车道、ILP 槽、空闲核、宽寄存器高位 | 冗余塞空闲资源,关键路径不增 |
| ③ 表示(编码) | 数值/路径表示里的余量 | 算术码(AN/残差)、控制流签名——检查退化成码字判断 |
| ④ 程序(数据流) | 后向切片、热/冷、循环重复、幂等区、边界 | 只在该检处检 / 跨迭代摊销 |
| ⑤ 环境(时间) | 故障率随轨道/任务可预测地变 | 决定"何时"加码(λ 自适应,暂放) |

## 每种数据类型有一个"主场层"(实测)

| 类别 | 主场层 | 机制 | 实测 |
|---|---|---|---|
| 浮点 | ② 资源 | SIMD 车道冗余 | fp64 8.9→0.2,**1.68×**(①并行×②车道叠加,近免费) |
| 整数·计算 | ③ 表示 | 残差码(mod M) | int_arith 9.8→**1.6**,**2.06×**;比复制(3.6/2.76×)又准又便宜 |
| 分支 | ② 资源(ILP 空槽) | 复制比较骑 ILP(SWIFT 式 cmp-DMR) | cmp_branch 29.2→**0.0**,**marginal≈0**(骑 ILP 近免费) |
| 地址 | ①递推 + ④切片 | 仿射下标切片检错 | cast→0,**1.91×** |

根因:**数据类型的本性决定主场**——浮点连续可并行(走②SIMD);整数离散精确(走③编码/残差);分支是离散判决、但复制一个比较极小→**骑②ILP 空槽近免费**(SWIFT, CGO'05 的核心洞见);地址仿射(走①递推+④切片)。

## 边界与地板(诚实)

- **整数③只对环运算计算成立**:load 在"编码那刻"共模,残差抓不住(11.7→10.4),需编码存储(更重的③)或回②;非环运算(位/比较)残差不组合,断链回地板。
- **无结构标量数据**:五层皆无可利用结构 → 复制,是可证的成本下界。
- **分支的①路径失败,改走②**:曾试"仿射循环 IV==bound 结构断言(层①)",但 **O3 向量化把规范循环变成多出口/非规范 IV → 断言 0 插入、0 覆盖**,且该不变量静态可证会被优化删除。改走②(ILP 空槽复制比较,SWIFT 式)稳而便宜。

## 横切洞见:优化与容错的"结构之争"

性能优化(向量化)对不同层**一边助力一边破坏**:助浮点的②(SIMD 红利摊销冗余),却毁分支的①(规范循环结构没了)。**结论不是"分支没救",而是"一层(①)被优化毁了,另一层(②ILP)接住"——这正是多层冗余的价值**。(与 P2"向量化把 cast 脆弱性上移"同源。)

## 统一主张(机制层)

> 识别计算在各层暴露的结构,匹配该层最便宜的检查;多层对齐时成本叠乘式下降(浮点=①×②)。
> 每类给出**成立域+边界**;某层被优化破坏时回退到另一层(分支①→②)。这是"从结构证明",不是 case-by-case。

机制归位:**②资源 = 浮点(SIMD)+ 分支(ILP);③编码 = 整数(残差码);①递推+④切片 = 地址**。
